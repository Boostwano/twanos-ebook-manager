# Twano R4 RC6 — Home Experience

RC6 replaces the statistics-heavy dashboard with a calmer, action-led Home page.

## Highlights

- Square, dark architectural hero banner with restrained corners.
- Home search for title, author, ISBN, publisher, filename and location.
- Five immediate results with Open Book and View in Library actions.
- Windows default reader support.
- Optional per-format reader applications for EPUB, PDF, MOBI/AZW and CBZ/CBR.
- Ask-for-reader and open-containing-folder modes.
- Library Summary, Recent Activity and Quick Actions panels.
- Smart library status banner.
- Analytics navigation placeholder ready for the RC7 Analytics Centre.
- Search handoff from Home to the full Library page.

## Scope intentionally deferred

- Built-in ebook rendering.
- Reading progress, bookmarks, highlights and Continue Reading.
- Full Analytics Centre, planned for RC7.
