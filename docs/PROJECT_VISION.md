# Twano Project Vision

**Tagline:** Your Library, Beautifully Organised.

Twano exists to make organising, protecting and rediscovering a digital library simple, safe and enjoyable.

Every feature should answer:

> Does this make organising a library easier, safer or more enjoyable?

## Product principles

- Beginner friendly
- Safe by design
- Preview before changes
- Automatic backups
- Unlimited Undo
- No vendor lock-in
- Calm, professional single-window interface
- Dark visual theme
- Beautiful rather than corporate

## Product direction

Twano is intended to evolve into a digital librarian, library organiser, metadata manager, discovery platform and plugin platform.
