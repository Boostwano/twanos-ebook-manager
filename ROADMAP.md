# Twano R4 Roadmap

## Current release — R4 Beta 2

Beta 1 is the accepted feature baseline. Beta 2 is the active reliability,
performance, provider, multi-folder, accessibility, and publication-hardening
package:

- metadata and cover art
- duplicate intelligence and recoverable quarantine
- actionable Library Health (without a full analytics dashboard)
- Calibre and network-library interoperability
- controlled plugins and providers
- completed settings, accessibility, and in-app guidance
- Windows packaging/update foundations
- combined watched-folder Preview All and protected Apply All
- GitHub publication safety, licensing, security policy, and automated tests

The feature scope remains controlled while Beta 2 completes real-computer
acceptance and production preparation.

## Remaining production path

### R4 Beta 2 acceptance gates

- complete the guided Beta 2 test schedule
- finish large-library and long-session stability checks
- finish high-DPI, keyboard, screen-reader, and contrast validation
- complete local, mapped, UNC/NAS, and Calibre-version matrices
- complete database/settings migration and recovery drills

### R4 RC1 — production candidate

- code freeze
- signed installer and portable build
- clean install, upgrade, uninstall/reinstall, and rollback validation
- final privacy, licence, dependency, and support review

### R4 Final

- publish the exact signed RC1 artefacts if no blocker is found
- release notes, checksums, known issues, support and update policy

## Deferred beyond R4 Final

- built-in ebook reader
- mobile or web applications
- cloud synchronisation
- reading-progress sync
- AI summaries or recommendations
- public unrestricted plugin marketplace
- multi-user server mode
